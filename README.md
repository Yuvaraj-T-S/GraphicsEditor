# Graphics Editor in C

## Overview

This project is a menu-driven 2D Graphics Editor developed in the C programming language as part of an academic assignment.
The application uses a character-based canvas implemented through a two-dimensional array and provides basic drawing and editing capabilities within a console environment.
The objective of the project is to demonstrate the use of arrays, functions, modular programming, and user interaction in C while simulating fundamental graphics operations.

## Current Progress

### Completed Features

* Canvas creation using a 2D character array
* Canvas initialization
* Canvas display in the console

### Planned Features

* Draw Line
* Draw Rectangle
* Draw Triangle
* Draw Circle
* Delete Objects
* Modify Objects
* Menu-driven interface
